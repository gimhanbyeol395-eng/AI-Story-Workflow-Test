# AI Narrative Workflow Test

## Goal
Test GPT for production-level storytelling (film-level narrative design)

## System
- Character psychology construction
- Long-form narrative structure
- Scene generation workflow

## Test Case

Character:
- Trauma: abandonment
- Goal: revenge
- Inner conflict: desire for connection vs fear of betrayal

## Scene Output

INT. CLUB ROOM – MORNING

Hanbyeol sits at the desk, vaping, calculating production costs.

She suddenly burns the budget paper with a lighter.

Nayeon enters, smoking.

Nayeon:
“I knew it would be like this.”

Hanbyeol:
“Did you expect something big?”

Nayeon:
“A girl came.”

Hanbyeol:
“Who?”

Nayeon:
“Maybe… my first love?”

Hanbyeol:
“You wanna die?”

At the door, Ryuran stands awkwardly, holding a single rose.

## Observed Issues
- Context loss in long sequences
- Character inconsistency across scenes
- Emotional drift over extended dialogue

## Conclusion
GPT shows strong capability in initial narrative generation, 
but breaks under long-form consistency requirements.
